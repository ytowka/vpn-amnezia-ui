# Поднятие тунеля

## enter

Туннель (transport IPv6, поверх — IPv4)
```bash
ip -6 tunnel add tun6 mode ipip6 local 2a12:5940:ebac::2 remote 2a03:6f02::423b
ip link set tun6 up
```

```bash
# Трафик к публичному v4 swe — в туннель (iptables DNAT не трогается)
ip route add 94.241.173.190/32 dev tun6
```


## Exit

```bash
ip -6 tunnel add tun6 mode ipip6 local 2a03:6f02::423b remote 2a12:5940:ebac::2
ip link set tun6 up
```

```bash
# Разрешить принимать v4-пакеты, прилетевшие через туннель
sysctl -w net.ipv4.conf.all.rp_filter=0

ip6tables -A INPUT -p 41 -s 2a12:5940:ebac::2/128 -d 2a03:6f02::423b/128 -j ACCEPT


sysctl -w net.ipv4.conf.tun6.rp_filter=0
sysctl -w net.ipv4.conf.default.rp_filter=0

sysctl net.ipv4.conf.tun6.rp_filter net.ipv4.conf.all.rp_filter
```
